A lot of you are asking. 

How BlueWallet handles wallet entropy  

Wallets created in BlueWallet use your device’s cryptographically secure system random number generator. The industry standard approach for generating keys. 

Want extra peace of mind? You can also add your own entropy using dice rolls or coin flips (Add wallet → Provide  entropy). BlueWallet lets users add entropy via dice or coin flips, and if insufficient manual entropy is provided, it fills the remainder from the system RNG. 

We regularly review this code, including with the latest AI-assisted tooling, and continuously test it as part of our development process. We ask you to do the same if you have the knowledge to do so.

Every build also runs runtime self-tests that generate large numbers of seeds and check for unexpected collisions. While no single test can prove an RNG is perfect, these checks are designed to catch obvious regressions before they ever reach users (this is important, your wallet should have this!).

You can even run the self-test yourself:
Settings → About → Self Test
