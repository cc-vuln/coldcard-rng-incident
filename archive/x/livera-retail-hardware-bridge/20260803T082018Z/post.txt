Getting a few DMs/questions about this, so sharing publicly. If you’re in a pinch and need to get off a 
@COLDCARDwallet
 quickly:

Hardware wallets (especially 
@Ledger
) are now stocked in physical tech stores in many places — e.g. Best Buy (US/Canada), JB Hi-Fi (Australia), Virgin Megastore  (UAE), MediaMarkt/Saturn (Germany/Italy/Spain), Currys (UK), Challenger (Singapore), etc.

Steps:
1. Move coins off your Coldcard onto a reputable phone wallet (
@BlockstreamApp
 or 
@bluewalletio
) as a temporary bridge
2. Walk into a tech store and buy a genuine hardware wallet
3. Set it up properly, verify it’s genuine, then migrate the coins
4. Now you have breathing space — take your time setting up proper multisig (or decide if a custodian is the right fit for you)

Treat the phone step as strictly temporary. Always check the device is genuine.
