COLDCARD VULNERABILITY DISCUSSION

An Unchained vault with
2 Coldcard-generated keys: Group A

• If 2 private keys are compromised (2 Coldcard-generated keys), an attacker still needs all 3 public keys associated with an address to access funds.

• A wallet configuration file has all 3 public keys for every vault address. Ensure you don't share your wallet configuration file. If you saved it, keep it private.

• Funds on re-used addresses are also vulnerable, because all 3 public keys for those addresses are public on the blockchain. We have attempted to identify and reach out to people in this situation. If you follow the normal pattern of clicking “Deposit” and generating a fresh address for each deposit, then you shouldn't be in this position.
