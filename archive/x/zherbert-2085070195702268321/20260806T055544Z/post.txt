The mystery bug was this:
Coldcard 4.0.0 accidentally initialized ckcc_vcp_enabled to true.

After the user logged in and USB became active, a connected computer could send Control-C, interrupt the interface, and enter Coldcard’s MicroPython REPL.

That provided firmware-level Python access and could expose wallet secrets.

Version 4.0.1 changed the flag to default to false.

The actual 4.0.0-to-4.0.1 diff makes this remarkably clear. Coinkite has also now explicitly identified it as the “USB serial REPL” vulnerability in its security-disclosure history.
