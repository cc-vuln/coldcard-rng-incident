We do not. There’s many reasons but the main one is KeyOS. 

KeyOS is a microkernel operating system powering Passport Prime. It took us 3 years to build. The kernel is around 9000 lines of code. It’s a much better security architecture than MicroPython based hardware wallets (or other architectures).

Once we release the app store in the coming weeks, youll be able to decide exactly what runs on your device (and what doesnt) 

You can already update the firmware without using Envoy app, the only thing you technically need it for right now is initial setup. At some point we will offer a setup option without Envoy as well. 

NFC is a core part of the backup options. Bluetooth isn’t just normal bluetooth; we put a separate chip on the board and create an encrypted tunnel through it (QuantumLink). KeyOS fully controls the bluetooth chip. It even controls the firmware running on it. If you turn off Bluetooth then it’s off.  

What attack model are you protecting yourself from? If it’s a malicious vendor then you should throw the device in the garbage or use it only in a Multisig. KeyOS is FOSS and builds are reproducible. You now have the power to verify exactly how it works for yourself.
