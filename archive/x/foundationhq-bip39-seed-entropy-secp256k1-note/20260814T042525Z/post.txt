Reminder: A properly generated 12-word BIP39 seed contains 128 bits of entropy, which is sufficient to protect Bitcoin funds.

secp256k1 uses 256-bit private keys but provides approximately 128 bits of classical security, because the best-known generic discrete-log attacks require roughly 2^128 work.

A 24-word seed increases the mnemonic search space to 256 bits, but it does not increase the approximately 128-bit classical security of the secp256k1 keys derived from it. 

Assuming a securely generated seed, that additional entropy provides little practical protection against brute-force attacks.
