I think the only real solution to AI-assisted cyber exploits is FOSS – real free and open source hardware and software.

Good guys equipped with frontier AI models (without restrictions) to find vulnerabilities in our codebases and in other codebases – and responsibly disclose to affected parties.

Black box stuff is not secure. Source-available code (not FOSS) is public but the industry has no incentive to review it because no one is allowed to build on it.

FOSS means anyone can build on it. Share libraries. Foundation uses BDK and rust-bitcoin libraries, for example. More shared FOSS code with more eyes on it is important.

The irony here is not lost to me that this Coldcard bug was introduced as part of a crusade to rip out all GPL code from the codebase.

Embrace FOSS, help each other out, work together as an industry, argue and compete with each other but still help each other and work together.

Also – be friendly with security researchers. Have a bug bounty program. Engage with the community. Take reports seriously.
