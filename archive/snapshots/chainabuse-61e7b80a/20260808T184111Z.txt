The same transaction simultaneously swept several hundred other victims' addresses, totaling approx 64.903 BTC. This is automated mass exploitation, not a targeted attack.




CAUSE: A firmware defect in my COLDCARD wallet (Coinkite Inc., Toronto, Canada), publicly acknowledged by the manufacturer on 2026-07-30; its CEO accepted accountability. In a 2021 library migration the build linked a weak software PRNG instead of the hardware true random number generator. The library libngu tested whether MICROPY_HW_ENABLE_RNG was defined rather than non-zero; Coinkite defined it as zero, so the build silently used the wrong implementation. Coinkite estimates affected seeds carry ~40 bits of entropy instead of 128 - exhaustively searchable on commodity hardware. An attacker enumerates candidate seeds offline, derives addresses, checks them against the public blockchain, and sweeps any holding funds. No device access is required, which is why my wallet remained physically secure throughout.




Affected firmware: Mk3 4.0.1+ (March 2021); Mk4/Mk5 before 5.6.0; Q before 1.5.0Q. My seed was generated on Mk3
