Code RED: Priority support for red teaming
Authors
NameGigiTwitter@dergigi
NameOpenSatsTwitter
The COLDCARD vulnerability that is currently being exploited shows that security flaws can go undetected for years, even catastrophic ones.
We want to do what we can to help the first responders that have been fire fighting, triaging, and red teaming as the industry digests what this exploit revealed. A lot of people have been working 24/7 in the last few days, doing everything in their power to reduce the damage that is being done.
We see it as our duty to allocate sats where they're needed most. And right now, support for the red team is duly needed. If you are red teaming critical Bitcoin software today, opensats.org/red is a priority path to funding, including reimbursement of past LLM token costs.

We will prioritize any red team applications for the foreseeable future.
Thank you for your work and support.
